# tbbapp-backend

Backend for **TbbApp**, the Tekirdağ Büyükşehir Belediyesi mobile app.

- **[`laravel/`](laravel/)** — the current backend (Laravel 12 + PostgreSQL).
  Start here; see its [README](laravel/README.md) for the API surface and how
  to run it.
- **[`node-old/`](node-old/)** — the previous Node/Express implementation,
  kept as reference. Not developed anymore; its features have been ported to
  the Laravel app.

Specs: [`backend-CLAUDE.md`](backend-CLAUDE.md) and [`BACKEND.md`](BACKEND.md)
hold the ratified architecture decisions and the API contract.
